# Pixel Run & Leap 設計規格

日期：2026-09-10
狀態：設計已確認，尚未進入實作

## 目標

建立一個僅供私人本機使用的 HTML5 2D 網頁遊戲，參考 `ffx0s/mario-html5` 的遊戲內容與素材，名稱與外層介面改為 `Pixel Run & Leap`。

第一版目標是接近參考專案的完整單人關卡流程，而非只有畫面展示。

## 已確認限制

- 技術：Phaser 3 + JavaScript。
- 建置：採用適合網頁遊戲的現代 JavaScript 建置流程，具體工具於實作規劃時確認。
- 平台：桌面與手機瀏覽器。
- 使用範圍：私人本機使用。
- 素材：使用參考專案的圖片、地圖、音樂與音效。
- 品牌：使用 `Pixel Run & Leap` 名稱，不保留參考專案的網站品牌。
- 本階段：只完成設計分析，不開始遊戲實作。

## 技術方向

Phaser 3 負責 2D 遊戲執行環境，包括畫面、Sprite、動畫、碰撞、攝影機、地圖、音效與場景。JavaScript 負責遊戲規則與物件行為，降低初期設定與 AI coding 迭代成本。

原生 Canvas 與 React + Phaser 外殼不列為第一版方案：前者需要自行實作較多遊戲基礎能力，後者會為目前的單一遊戲增加不必要的整合複雜度。

## 場景架構

```text
BootScene
  初始化 Phaser 設定

PreloadScene
  載入圖片、Sprite、地圖、音樂與音效

TitleScene
  Pixel Run & Leap 標題畫面
  開始遊戲與音效開關

GameScene
  玩家、敵人、磚塊、金幣、道具與終點
  地圖捲動、碰撞與 HUD

GameOverScene
  生命歸零、重新開始

LevelCompleteScene
  顯示分數、通關結果與下一步操作
```

預計將程式碼依功能拆分為 `scenes/`、`entities/`、`systems/` 與 `assets/`，避免所有邏輯集中在單一場景。

## 遊戲功能

- 左右移動與跳躍。
- 踩踏敵人。
- 撞擊磚塊。
- 收集金幣。
- 蘑菇、星星等道具。
- 玩家受傷、死亡與生命數。
- 分數與倒數時間。
- 旗幟或終點判定。
- 關卡完成與重新開始。
- 背景音樂、事件音效與音效開關。

### 桌面操作

```text
左方向鍵 / A：向左
右方向鍵 / D：向右
Space：跳躍
P：暫停
M：音效開關
```

### 手機操作

畫面底部提供固定觸控按鈕：

```text
[ 左 ] [ 右 ]              [ 跳躍 ]
```

觸控按鈕與鍵盤共用同一套輸入狀態，遊戲規則只維護一份。

## 視覺與介面

保留參考素材的像素風格，外層介面改為 `Pixel Run & Leap`：

- 自有遊戲標題與開始畫面。
- 像素風邊框與深色藍色背景。
- HUD 顯示分數、金幣、生命與時間。
- 桌面版隱藏觸控按鈕，手機版顯示觸控按鈕。
- 遊戲區維持固定比例，使用縮放與置中避免變形。
- 遊戲 Canvas 與 HTML/CSS 外層 UI 分離。

資源會集中管理並保留原始檔名與來源記錄。音樂在使用者點擊開始後播放，以符合手機瀏覽器的自動播放限制。

## 狀態管理

集中管理以下遊戲狀態：

- 玩家生命。
- 分數。
- 金幣數。
- 剩餘時間。
- 當前關卡。
- 音效與音樂開關。

場景之間只傳遞必要資料，避免不同物件各自維護分數或生命。

## 錯誤處理

- 素材載入失敗時顯示明確錯誤訊息。
- 地圖資料格式錯誤時阻止進入遊戲並顯示診斷資訊。
- WebGL 不可用時嘗試退回 Canvas。
- 音樂被瀏覽器阻擋時等待使用者互動後播放。
- 視窗尺寸變更時重新計算遊戲區與觸控按鈕位置。
